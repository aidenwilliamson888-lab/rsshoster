Podcast Sitemap & RSS Generator

Build a sitemap.xml and an RSS XML file from a public RSS feed, an imported CSV/JSON file, or episode URLs you can verify. Nothing is uploaded to a server by this page.

01 · Source input

Pocket Casts is a podcast directory/player, not the audio host. Its page may not expose the original feed or all episodes to browser scripts.
Supported fields include title, link/url, description, pubDate/date, guid, audio/enclosure/audioUrl. JSON can be an array or an object with an episodes array.
Only URLs you provide are used; the tool does not guess episode URLs.
Important: A sitemap lists public web page URLs. A podcast-ready RSS feed normally needs a real audio enclosure URL for every episode. If the source only contains episode page links, the generated RSS will include those links but cannot guarantee playback in podcast apps.

Why Pocket Casts may fail

Browsers restrict cross-origin requests (CORS), and the Pocket Casts page may block automated access. If direct loading fails, use the original public RSS feed URL, paste the feed XML, or import an exported CSV/JSON file. If you control a server, a small backend proxy may be needed to fetch sources that block browser requests. A proxy cannot bypass authentication or other access controls.

03 · Download generated files

Files are generated locally in your browser. Sitemap entries are created only from discovered/provided page URLs. RSS output includes enclosure tags only when a real audio URL exists in the input.
